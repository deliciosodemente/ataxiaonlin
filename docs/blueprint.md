# **App Name**: Ataxia Collective

## Core Features:

- Event Schedule: Display event details: date, time, location, and performers.
- Merchandise Display: Showcase available merchandise with images, descriptions, and prices.
- Contact Form: Allow users to submit collaboration and suggestion forms.
- AI Playlist Generator: A tool which creates personalized event playlist suggestions based on user preferences (genres, artists).
- Audio Player: Music playback functionality for song previews or promotional tracks.

## Style Guidelines:

- Primary color: Dark, deep blues (#121212) to reflect the night sky and electronic atmosphere.
- Secondary colors: Muted purples and pinks (#800080, #FF69B4) to create a vibrant contrast against the dark background.
- Accent: Electric green (#00FF00) for interactive elements and highlights.
- Clean, modern, sans-serif fonts for headlines and body text.
- Minimalist icons with a neon aesthetic.
- Full-screen layouts with parallax scrolling effects.
- Subtle animations and transitions for interactive elements and page loading.
